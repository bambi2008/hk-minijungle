## 3. 原始产品定义摘要

### 3.1 品牌与定位

- 品牌：AquaClick
- 产品：模块化可水洗智能宠物喂食器
- 目标市场：欧美 Amazon、独立站、众筹市场
- 核心差异化：
  - 食物接触/出粮总成可整体拆洗
  - 磁吸与机械锁止结合的模块化架构
  - 可选摄像头、AI、多猫、表情屏和开放模块
  - 本地存储、无强制云订阅的可能性
  - 通过模块及联名形成长期生态

### 3.2 三大总成

1. 食物仓总成：透明仓、盖体、密封、转子/搅龙、出粮检测、可拆食盆。
2. 电气仓总成：电机、主板、电源、RTC、离线计划、显示与告警。
3. 拓展模块总成：基础摄像头、AI 摄像头、表情屏、开放模块。

### 3.3 产品线设想

- 基础版
- Wi-Fi 版
- 摄像头版
- AI 多猫版
- 表情屏及开放模块作为可选扩展

## 4. 当前冻结的 V0.1A/V0.1B 工程基线

### 4.1 关键目标

| 项目 | 当前基线 |
|---|---|
| 食品 | 普通干粮 + 少量冻干 |
| 粒径 | 约 5–15 mm |
| 冻干比例 | EVT 暂定不超过总体积 20%，待测试 |
| 可用容量 | 目标 3.35 L；可接受 3.20–3.50 L |
| 食物仓外径 | 目标 180 mm；EVT 备选 185 mm |
| 产品总高 | 不超过约 305 mm |
| 单餐档位 | 10 g / 20 g / 40 g，最终需按粮型校准 |
| 称重 | 标准配置方向：2 kg 单点式称重传感器 |
| 清洗声明 | 冲洗、浸泡、手洗；当前不承诺洗碗机 |
| 可水洗件 | 食物仓、转子、出粮通道内衬、食盆 |
| 电气件 | 不进入可水洗总成 |
| 转子验证 | A/B/C 三方案并行 |
| 快拆验证 | 双侧释放与中央杠杆释放并行比较 |

### 4.2 需要纠正的原始技术点

- ESP32-C3 通常不支持 5 GHz Wi-Fi；原说明中的“2.4G/5G 双频”不能直接沿用，需重新选型或改为 2.4 GHz。
- IPX7 是测试等级，不等同于“可随意洗碗机清洗”；营销声明必须经过对应测试。
- 磁铁不应单独承担安全锁止，建议磁吸负责定位与手感，机械机构负责抗抬起和防误分离。
- PC 是否适合所有食品接触、耐刮、耐清洁剂和长期透明需求，需结合材料法规和 OEM 工艺评估。
- “AI 猫脸识别实现多猫独立定量”仅靠视觉通常不能阻止其他猫抢食；需要与 RFID、门控或受控食盆方案结合评估。

## 6. 当前 CAD 的真实成熟度

以下限制必须保留，不得在后续宣传或工程沟通中省略：

- 食物仓是简化的轴对称圆柱/锥台组合，不是真正偏心复合坡面。
- 出口是简化几何，没有完成真实的入口过渡、圆角、拔模和死角处理。
- A/B/C 转子是刚性梯形叶片包络，不是真实弯曲柔性硅胶叶片。
- 出粮通道 STEP 当前主要表示流道实体，不是具有壁厚、卡扣和清洗拆装细节的真实内衬零件。
- 快拆结构只是空间包络，不是完整挂钩、杠杆、弹簧、行程和公差机构。
- 联轴器是概念包络，尚未完成浮动量、弹簧、套筒、防尘迷宫和磨损设计。
- 称重托盘尚未完成传力路径、过载限位、线束和防侧向力设计。
- 当前文件不是开模数据，不是生产图，也不能直接用于性能结论。

## 8. 数字环境中尚未完成、但仍可继续做的工作

按优先级建议如下。

### P0：影响 EVT 样机正确性的结构工作

1. 将食物仓底部改为真实偏心复合坡面，使粮食自然汇聚到转子入口，并评估最小坡角。
2. 从有效容量中扣除转子、搅拌结构、圆角、出口侵入体积和安全余量，重新确定 3.35 L 填充线。
3. 为 A/B/C 转子建立动态旋转包络，检查与仓体、窗口和通道的干涉。
4. 对所有转子 × 窗口 × 通道组合做静态最小通过截面检查，特别关注 15 mm 颗粒和不规则冻干。
5. 将标准/加宽通道改成真实可拆洗内衬：有壁厚、拔模、圆角、定位、卡扣和手指操作空间。
6. 细化浮动联轴器：轴向/径向/角向补偿、弹簧预压、套筒、食物粉尘隔离、可洗件与电机轴的边界。
7. 细化双侧快拆和中央杠杆快拆，建立挂钩、锁止面、释放行程、弹簧、误触保护和装配公差链。
8. 细化称重结构：传力路径、2 kg 传感器安装、过载限位、线束余量、防侧向力和清洁液隔离。

### P1：可制造性与工程验证文件

1. 做关键力学估算：转子堵转扭矩、联轴器应力、锁扣保持力、释放操作力、磁吸定位力。
2. 建立关键公差表和最坏情况公差链。
3. 输出可供 OEM 讨论的二维工程图：基准、关键尺寸、材料、表面、拔模、圆角和 CTQ。
4. 输出装配关系图和爆炸图，明确可洗区/不可洗区和密封边界。
5. 完成 DFMEA 初版，将每个高风险项映射到 EVT 测试。

### P2：产品与商业执行深化

1. 审核工作簿所有页面的视觉和公式一致性。
2. 补齐众筹页面信息架构、核心演示脚本、FAQ 和风险披露。
3. 制定 Click 模块接口规范 V0.1：机械包络、电气触点、握手协议、功耗、ID、安全限制。
4. 建立联名模块准入规则：品牌适配、食品/宠物安全、责任边界、认证和收入分成。
5. 对当前全部数字交付做一次最终红队审查，生成“已知问题/不得宣称/下一阶段准入条件”报告。

## 9. 只能通过实物、实验室或 OEM 完成的事项

下列工作不能由纯数字建模替代：

- 真实 5–15 mm 干粮及冻干的流动、架桥、卡粮和剂量离散性测试。
- 柔性硅胶叶片的变形、疲劳、碎粮率和清洁残留测试。
- 电机真实扭矩、堵转电流、温升、噪声和寿命测试。
- 快拆机构的人机操作力、跌落保持、儿童/宠物误触和循环寿命。
- 冲洗、浸泡、干燥、异味、霉菌风险和多次清洗后的密封可靠性。
- 食品接触材料法规、迁移测试、FDA/EU 合规和第三方认证。
- OEM 注塑 DFM、模具方案、正式 BOM、报价、MOQ 和交期。
- 摄像头隐私、无线合规、FCC/CE/UKCA 等认证路径。
